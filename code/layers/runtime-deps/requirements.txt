# =============================================================================
# layers/runtime-deps/requirements.txt — dependências de RUNTIME da Lambda Layer
# -----------------------------------------------------------------------------
# Este arquivo alimenta a Lambda Layer montada por `sam build` (BuildMethod
# python3.12). Ele lista APENAS o que o handler de execução importa em runtime
# no AWS Lambda; o `sam build` resolve as transitivas (starlette, pydantic-core,
# anyio, typing-extensions, etc.) a partir destas raízes.
#
# Versões EXATAS, espelhando as `dependencies` do pyproject.toml (Req 4.4 / 5.4)
# para que o pacote da Layer seja idêntico ao ambiente local/CI.
#
# Incluídos (o que `interface/api/main.py -> handler = Mangum(build_app())`
# realmente carrega no Lambda):
#   - fastapi : define a app HTTP e as rotas (GET /health).
#   - mangum  : adapta a app ASGI ao evento do API Gateway (ponto de entrada).
#   - pydantic: modelos/validação usados por FastAPI e pela config.
#
# Excluídos de propósito:
#   - uvicorn : servidor ASGI usado SÓ na execução local (uvicorn/CLI). No
#               Lambda quem invoca a app é o Mangum, não um servidor — carregá-lo
#               só engordaria a Layer.
#   - boto3   : já é PROVIDO pelo runtime do AWS Lambda e só é usado por import
#               tardio no adapter de Secrets Manager; fixá-lo aqui duplicaria o
#               SDK e inflaria a Layer sem necessidade.
#   - opentelemetry-* : extra opcional (grupo `otel`), carregado por import
#               tardio quando o tracing liga; fora do runtime mínimo do bootstrap.
# =============================================================================
fastapi==0.115.6
mangum==0.19.0
pydantic==2.10.4
