# Superpowers

Dependência opcional de workflow, não incluída nem instalada. Use as skills fornecidas por uma instalação confiável do Superpowers; este pacote não redistribui seu código.

| Fase do workflow | Skill quando disponível |
| --- | --- |
| Entender e aprovar desenho | superpowers:brainstorming |
| Planejar | superpowers:writing-plans |
| Executar | superpowers:executing-plans ou superpowers:subagent-driven-development |
| Solicitar revisão | superpowers:requesting-code-review |
| Tratar apontamentos | superpowers:receiving-code-review |
| Verificar conclusão | superpowers:verification-before-completion |

O agente principal continua orquestrador. As skills organizam o processo; os especialistas trazem expertise. Se uma skill estiver indisponível, registre a limitação e siga os gates documentados pelo template sem declarar que a skill foi executada. Revisão independente, correção e nova revisão permanecem necessárias.
